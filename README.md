# Claude Simulation (Skills Bank)

Interactive training replica of the Claude interface (November 2026), for trainees who do not have Claude accounts.

- **Explore:** the Claude interface opens directly. Every button, menu and field works.
- **Assistant:** click any button and a card explains what it does, why it helps at work, and which plan has it. "Explain before clicking" lets trainees read first. With live AI on, they can also ask free questions.
- **Plans:** switch between Free, Pro, Max, Team and Enterprise. Paid features appear only on plans that include them, with a side-by-side comparison.
- **Feature map:** pick a feature and the simulator opens it and highlights where it is.
- **How do I…?** 14 guided how-tos in Watch and Try.
- English / Arabic, full screen (press F). Single file: `index.html`.
- Live AI uses the same Skills Bank Cloudflare Worker and session codes as the ChatGPT simulation (see the ChatGPT package's SETUP-AI.md). No extra setup.
